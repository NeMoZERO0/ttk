Инженерная база

Технологический стек простыми словами

Современные и проверенные технологии, обеспечивающие высокую скорость и надежность работы без лишней сложности.

Фронтенд
React 19 + Vite
Моментальный запуск интерфейса за доли секунды, плавная анимация и работа без зависаний даже на бюджетных телефонах.
Отрисовка карты
Векторный SVG
Четкие линии при любом приближении. Векторный файл карты весит в десятки раз меньше тяжелых растровых картинок.
Сервер
Python (FastAPI)
Современный асинхронный сервер. Высокая скорость построения маршрутов и стабильная обработка запросов гостей.
База данных
PostgreSQL
Надежное промышленное хранилище для мероприятий, планов этажей, маршрутов и статистики посещений.
Отказоустойчивость
Резервный SQLite
Автоматическое плавное переключение на встроенную локальную базу при работе на автономных стендах без Docker.
Развертывание
Docker
Упаковка всего приложения в изолированные контейнеры. Запуск на любом сервере или ноутбуке одной командой.
